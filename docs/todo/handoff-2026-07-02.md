## 2. The installer / distribution effort — state

**Goal:** a browser `install.php` an operator drops on shared hosting (HETEML/
sakura), which sets up the DB, picks single/multi tenancy, downloads the app, and
creates the first admin.

**Locked decisions (owner):**
1. **Generalize from nene-invoice's installer** (common lib extracted *after* the
   PoC proves the shape — invoice's `public_html/install.php` is the most complete
   sibling; nene-corpus's `src/Install/` is the cleanest architecture).
2. **Clear gets Tier A** by owner override of the #193/#206 retraction — with a
   prominent "not recommended for bank/PII, at your own risk" warning.
3. **Download source = `nene-origin.dev`, not GitHub.** The domain is acquired and
   serves HTTPS static files. install.php will read **`NENE_ORIGIN_URL`** (default
   `https://nene-origin.dev`). This matches Origin's design (its live-CDN publish is
   human-gated/out-of-band for now = we place artifacts by hand).
4. **Thin PoC, sliced.**

**Slices:**
- ✅ **Slice 1** — install.php wizard (DB / tenancy / migrate / admin). #232.
- ✅ **Slice 2** — release-build (bundled ZIP) + ship Phinx. #236.
- ⬜ **Slice 3 (NEXT)** — install.php fetches the release from Origin. See §3.
- ⬜ Later — commonize the installer (invoice ↔ clear); JWS signature verification
  + the real `current → snapshot → targets` chain; an `InstallHttpTest`; wiring
  `/machine/health` app version + NENE2 `DatabaseCandidateInspector` preflight.

**Manual-publish artifacts (rebuild anytime with `composer release:zip`; `build/`
is gitignored so they are NOT in the repo):**
- `build/release/nene-clear-0.1.0.zip` (~16 MB, vendor + admin UI bundled).
- `build/release/latest.json` — a valid Origin `targets` object with
  `artifact_sha256` = **`e284e8fd3a595ca0a1748432359a53d76e61dd820c6822360120027016f193b1`**
  (for the 0.1.0 build). Upload both to `nene-origin.dev`:
  - ZIP → e.g. `https://nene-origin.dev/nene-clear/nene-clear-0.1.0.zip`
  - manifest → `https://nene-origin.dev/nene-clear/stable/latest.json`
  - (adjust `artifact_url` host to wherever the ZIP actually lands.)

## 3. Next: Slice 3 (actionable spec)

Add an **acquire** step to `public_html/install.php`:

1. Read `NENE_ORIGIN_URL` (default `https://nene-origin.dev`).
2. `GET {NENE_ORIGIN_URL}/nene-clear/stable/latest.json` → parse as an Origin
   `targets` object.
3. Download `latest.artifact_url`; verify `latest.artifact_sha256` (**before**
   touching anything).
4. Zip-slip-safe extract into place (only needed when `vendor/`/`src/` are absent —
   the "fresh upload, no shell" case; skip when the code is already present).
5. Then continue the existing wizard (DB → tenancy → migrate → admin).

**Test without touching the real host:** serve `latest.json` + the ZIP from a local
mock origin (`php -S`), point `NENE_ORIGIN_URL` at it, and confirm
fetch → verify → extract → install → login. The same code then works against
`nene-origin.dev` once the files are uploaded.

**Origin contract (verified in `../nene-origin`):**
- Real read path: `/v1/{product}/{channel}/current → /snapshot/{sha} → /v1/targets/{sha} → artifact` (`cdn.nene-origin.dev/{product}/...`). Signed Ed25519 / detached-JWS.
- `targets` schema (`docs/spec/targets.schema.json`): `spec_version, schema_version, product, channel, latest{version, released_at, artifact_url, artifact_sha256, changelog_url?, min_php?, requires?}, min_supported_version, channels[], provenance?`.
- Tier A atomic-apply rules: `docs/adr/0001-origin-update-contract.md` §5.
- Tooling: `bin/origin-sign` (Phase 2, dev keys, local), `bin/origin-publish` (Phase 3, local mirror only — **live CDN push is not built**; manual placement is the interim, by design).
- nene-clear is a registered product: `docs/explanation/products/nene-clear.md`.
- Our stopgap deliberately serves a single `latest.json` (avoids the reserved
  `current` name) and verifies via HTTPS + sha256; JWS + the full chain come later.

**Doc debt to fix in Slice 3:** the `install.php` docstring and
`docs/explanation/requirements.md` still say "GitHub download" — change to
"nene-origin / NENE_ORIGIN_URL".
